# v1.3.0 설치 브라우저 검증

후속 검사: [2026-10-24 연결·복구 보완판 최종 결과](CONNECTION-TEST-2026-10-24.md). 아래는 당시 상태를 보존한 기록입니다.

2026-10-18 기준입니다. 실제 설치 브라우저, 사용자 확인, 격리 시험 브라우저의 결과를 구분합니다.

## 실행 환경

- Chrome·Comet 확장 v1.3.0과 팝업의 GPT-6 Luna 선택·저장을 확인했습니다.
- Windows 재시작 보완판 r2 적용 후 실제 연결 프로그램의 `/health`에서 `version: 1.3.0`, `modelSelection: true`를 확인했습니다.
- 연결 코드 불일치가 발생해 연결 화면을 새로고침한 뒤 두 브라우저에 현재 코드를 다시 저장했습니다. ChatGPT 로그인 연결 상태는 정상이었습니다.
- 검사 페이지: [NVIDIA Isaac Sim ROS 2 문서](https://docs.isaacsim.omniverse.nvidia.com/latest/ros2_tutorials/index.html).

## 확인된 결과

| 항목 | Chrome | Comet |
|---|---|---|
| 스페이스바 3회 입력 번역 | 도구로 직접 실행·확인 | 사용자가 정상 작동을 확인 |
| 번역 모델 표시 | 완료 안내의 GPT-6 Luna 확인 | 팝업에서 GPT-6 Luna 선택·저장 확인; 이번 입력 결과의 모델 표시는 별도 확인하지 못함 |
| 입력 원문 복구 | 원문 일치와 검색창 열림 유지 확인 | 이번 v1.3.0 설치 검사에서는 미확인 |
| 복구 버튼 유지 | 완료 확인 후 49초가 지나도 표시되고 클릭 가능 | 이번 v1.3.0 설치 검사에서는 미확인 |
| 페이지 원문·번역 병기 및 페이지 복원 | 이번 v1.3.0 설치 검사에서는 미확인 | 이번 v1.3.0 설치 검사에서는 미확인 |

Chrome 입력 예문은 `로봇 센서의 지연 시간을 확인하고 설정을 유지합니다.`였으며, 결과는 `Check the robot sensor’s latency and maintain the settings.`였습니다. 원문 복구 후 같은 한국어 문장으로 돌아왔고 검색 모달은 열려 있었습니다. 49초는 버튼 유지 관찰 시간이며 번역 소요 시간이 아닙니다.

Comet 검사에서는 확장 새로고침 후 기존 문서에 남은 코드가 갱신 오류를 표시해 문서를 새로고침했습니다. 이후 Computer Use가 현재 브라우저 URL을 확실히 확인하지 못해 자동 조작을 종료했습니다. 사용자가 이후 Comet의 스페이스바 3회 번역 작동을 확인했습니다. 이 확인을 도구의 독립적인 완료 검증으로 표기하지 않습니다.

## 기존 검사와 남은 범위

- v1.3.0 JavaScript 구문 검사, 단위 20개, 모의 API 브라우저 회귀 25개, Windows 실행 파일 모의 검사 12개가 통과했습니다. 실행 파일 r2 커밋의 GitHub CI도 통과했습니다.
- 격리된 Chrome for Testing에서는 실제 ChatGPT 로그인으로 두 Luna 모델의 선택·저장·재로드, 페이지 병기, 스페이스 3회 번역, 입력·페이지 원문 복구와 NVIDIA 검색 모달 유지가 확인됐습니다. [모델 비교 및 검사 범위](MODELS-1.3.0.md).
- 사용자의 설치된 Chrome·Comet에서 **새 모델을 적용한 페이지 병기·복원**, Comet의 **입력 원문 복구·복구 버튼 유지**는 최종 재검증이 남아 있습니다. [v1.2.2의 설치 브라우저 검사](SEARCH-1.2.2.md)를 이번 모델 적용 후의 결과로 대체하지 않습니다.
- 브라우저 화면 증거는 로컬 작업 폴더에 보관했습니다. 개인 탭·북마크·연결 코드가 포함될 수 있는 자료는 공개 저장소에 추가하지 않았습니다.
