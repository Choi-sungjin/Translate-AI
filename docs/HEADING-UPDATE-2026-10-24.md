# 제목 바로가기 기호 보완판 · 2026-10-24

NVIDIA Isaac Sim 문서에서 `ROS 2#`, `관련 문서#`처럼 번역 제목 끝에 `#`가 붙는 문제를 고쳤습니다. 문서의 제목 바로가기 링크에 들어 있는 기호가 번역 원문에 섞였던 문제입니다.

## 변경과 적용

제목 안의 `headerlink`, `header-anchor`, `anchor-link` 링크가 같은 페이지의 위치를 가리키고 기호만 담을 때, 번역 원문을 수집하는 과정에서 그 기호를 제외합니다. 실제 DOM과 바로가기 링크는 그대로 둡니다. `C#`, `#include`, 제목 안의 의미 있는 링크 문구, 본문의 `#`는 제거하지 않습니다.

이 보완판은 이전 초점 이동 후 입력 원문 복구 수정도 포함합니다. `Translate-AI-heading-update-20261024.zip`의 `extension/content.js`를 기존 설치 폴더의 같은 파일에 덮어쓰고, **각 브라우저의 확장 새로고침 → 대상 웹페이지 F5** 순서로 적용합니다. 전체 확장 설치용 ZIP이 아니며 v1.3.0/v1.4.0의 버전 파일·실행 프로그램·설정을 유지합니다. 연결 프로그램 재시작이나 연결 코드 재저장은 필요 없습니다.

## 재현 및 자동 검사

수정 전 추가한 검사는 `Translated: ROS 2`를 기대했지만 `Translated: ROS 2#`를 받아 실패했습니다. 수정 후 같은 검사가 통과했습니다. 기호 제외뿐 아니라 의미 있는 `#` 보존, 원래 링크 주소·클릭 처리 유지, 원문 복원 후 DOM 일치도 확인합니다.

- JavaScript 구문 검사 통과.
- 단위 검사 21개 통과.
- 전체 브라우저 회귀 검사 27개 통과.

회귀 번역 응답은 결정적인 로컬 모의 API입니다. 아래 설치 브라우저의 실제 계정 번역과 구분합니다.

## 설치된 Chrome·Comet 최종 검사

Windows v1.3.0 설치본에 이번 보완 파일을 적용한 뒤 NVIDIA Isaac Sim ROS 2 문서에서 검사합니다. Linux 설치 브라우저의 실기 결과를 의미하지 않습니다.

양쪽 확장과 문서를 새로고침한 뒤 사용자가 페이지 번역을 시작했습니다. 이후 제목·병기 관찰, 스페이스바 3회 입력, 유지 시간 측정, 복구 조작과 결과 비교는 도구로 직접 수행했습니다. 번역 모델은 **GPT-6 Luna**입니다.

| 검사 | 설치된 Chrome | 설치된 Comet |
|---|---|---|
| 제목 기호 | ROS 2 / 관련 문서 / 마이그레이션 / 참고에 추가 # 없음 | 같은 네 제목에 추가 # 없음 |
| 페이지 병기 | 22/22 완료, 영문·한국어 함께 표시 | 22/22 완료, 영문·한국어 함께 표시 |
| Space 3회 입력 번역 | 실제 영어 번역 완료 | 실제 영어 번역 완료 |
| 입력 복구 버튼 유지 | 완료 관찰 후 **81초**에도 표시 | 완료 관찰 후 **68초**에도 표시 |
| 초점 이동 후 입력 복구 | Tab → Enter로 정확한 원문 복구, 검색 모달 열림 유지 | Tab → Enter로 정확한 원문 복구, 검색 모달 열림 유지 |
| 페이지 원문 복원 | 한국어 병기 제거, 앞서 저장한 영문 본문 1,550자와 문자열 완전 일치 | 한국어 병기 제거, 네 원문 제목·영문 문서와 복원 완료 안내를 화면·접근성 트리로 확인 |

Chrome 예문: `크롬에서 제목을 확인하고 원문을 안전하게 복구합니다.` → `Check the title in Chrome and safely restore the original text.` → 같은 한국어 원문.

Comet 예문: `코멧에서 제목을 확인하고 원문을 안전하게 복구합니다.` → `Check the title in Comet and safely restore the original text.` → 같은 한국어 원문.

81초·68초는 **번역 완료 관찰 후 버튼 유지 시간**이며 번역 소요 시간이 아닙니다. 이번 실기는 NVIDIA 문서 기준이며 모든 사이트의 편집기나 실제 한글 IME 조합 전체를 보장하지 않습니다. Comet 결과를 DOM 전체 문자열 비교로 확대하지 않습니다.
