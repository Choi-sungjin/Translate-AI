# 페이지 번역 속도 개선 — v1.2.0

사용자가 Perplexity 브라우저에서 [NVIDIA ROS 2 문서](https://docs.isaacsim.omniverse.nvidia.com/latest/ros2_tutorials/index.html)를 번역할 때 매우 느리다고 보고했습니다. 기존 코드는 문단 하나마다 Codex CLI를 실행하고 로컬 연결 프로그램이 요청을 하나씩 처리했습니다.

## 변경

- 페이지 텍스트를 최대 12개·합계 12,000자씩 묶어 한 번의 모델 요청으로 번역합니다. 문단 ID, 개수, 중복, 누락을 검사한 뒤 각 원문 아래에 배치합니다.
- 브라우저에서도 묶음당 HTTP 요청 하나를 사용합니다. 페이지 요청은 한 번에 하나만 보내 연결 슬롯을 모두 점유하지 않습니다.
- 입력 번역은 페이지 대기열과 분리합니다. 로컬 프로그램은 페이지 묶음 1개와 입력 요청 1개, 최대 2개의 번역을 동시에 실행합니다.
- 기존 문단별 요청도 지원하므로 이전 확장은 새 연결 프로그램에 접속할 수 있습니다. 새 확장의 묶음 전송에는 새 연결 프로그램이 필요합니다.
- 설정을 읽기 전에는 설정 폼을 잠급니다. 빠르게 서비스를 바꾸면 뒤늦게 불러온 값이 덮어쓰던 문제를 회귀 검사에서 찾아 수정했습니다.

## 실제 측정

2026-10-18, 같은 ChatGPT 로그인과 Codex CLI 0.162.1 사용. API 키와 번역 캐시 없이 NVIDIA 공개 텍스트의 같은 12개 항목을 비교했습니다.

| 측정 | 시간 |
| --- | ---: |
| 기존 연결 프로그램, 12개 문단 순차 요청 | 86.944초 |
| 새 연결 프로그램, 같은 12개 항목 한 묶음 | 13.684초 |
| 위 1회 비교의 속도 차이 | 약 6.35배 |

첫 번역이 바로 나타나는 방식은 아닙니다. 묶음이 완료된 뒤 결과가 함께 표시되며, 속도는 문단 길이·계정·서버 상태에 따라 달라집니다. 이 수치는 모든 사이트의 보장 속도가 아닙니다.

별도 Chrome for Testing 156에서 실제 NVIDIA URL에 확장을 로드하고 실제 ChatGPT로 검사한 결과:

- 처음 12개 번역: 11.951초. 스크롤하며 22개 항목을 번역하고 원문 복원까지: 20.313초.
- 원문 텍스트와 링크 주소가 유지되고, 번역 해제 시 원문이 정확히 복구됐습니다.
- 페이지 번역 중 다른 탭에서 스페이스바 3회로 시작한 입력 번역: 6.536초. 당시 페이지 완료 문단은 0개였으므로 페이지 결과를 기다리지 않고 입력이 먼저 완료됐습니다. 입력 원문 복원도 확인했습니다.
- 실제 로그인 검사 4개 통과. 별도 브라우저 회귀 검사 18개와 단위 검사 17개 통과. 입력 조합·늦은 응답·문단 결과 매핑·인증·요청 제한을 포함합니다.

[측정 수치 JSON](performance-2026-10-18.json). 원문·번역 전체와 로컬 로그인 테스트 산출물은 저장소에 올리지 않습니다.

사용자가 사용하는 Perplexity 브라우저는 도구에 연결되지 않아 직접 검증하지 못했습니다. 위 결과는 별도 테스트 브라우저에서 얻은 증거이며 사용자 설치본의 갱신 완료를 뜻하지 않습니다.

## 적용

1. 최신 소스 또는 새 패키지를 준비합니다.
2. `Stop-Translate-AI.cmd`를 실행한 뒤 `Start-Translate-AI.cmd`를 실행합니다. 기존 연결 코드는 유지됩니다.
3. 사용 중인 브라우저의 확장 관리 화면에서 Translate AI를 새로고침하고 NVIDIA 페이지도 새로고침합니다.

새 연결 프로그램의 `/health`는 `version: "1.2.0"`, `pageBatchTransport: true`를 반환합니다. 구버전이 켜져 있으면 새 확장은 로컬 프로그램 업데이트·재실행 안내를 표시합니다.

검사 중 최종 로컬 프로그램 재시작 명령이 자동 승인 정책으로 차단돼, 기존 프로그램을 중단하지 않는 별도 포트와 테스트용 확장 복사본으로 최종 실사용 API 검사를 완료했습니다. 사용자 설치본에는 위 재시작·새로고침 단계가 남아 있습니다.
