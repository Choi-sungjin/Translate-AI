# Chrome v1.2.1 검증 — 2026-10-18

## 변경 사항

입력 번역의 **원문 복구** 알림은 기존 10초 제한을 없앴습니다. 복구하거나 **닫기**를 누르거나 다른 번역 알림으로 바뀔 때까지 유지합니다. 번역 대기 알림도 결과가 나올 때까지 유지하며, 일반 안내는 30초 후 닫힙니다. 입력 알림이 표시되는 동안 페이지 번역 진행률이 복구 버튼을 덮어쓰지 않습니다. 페이지 번역이 켜져 있다면 알림을 닫은 뒤 페이지 상태가 다시 표시됩니다.

페이지 묶음 처리와 입력 전용 처리 경로는 v1.2.0의 속도 개선을 그대로 사용합니다. 로컬 연결 프로그램의 `/health` 버전은 1.2.0이며 확장 v1.2.1과 호환됩니다. 이번 UI 수정 때문에 연결 프로그램을 재시작할 필요는 없습니다.

## 사용자의 실제 Chrome

사용자가 확장을 새로고침한 뒤 공개 [httpbin 입력 폼](https://httpbin.org/forms/post)을 새 탭에서 열었습니다. 테스트용 문장만 입력했으며 폼은 제출하지 않았습니다.

- 입력: `크롬에서 번역한 문장을 기다렸다가 원문으로 복구합니다.`
- 스페이스 키 3회 후 실제 결과: `Waits for the translated text in Chrome, then restores the original text.`
- 새 **닫기** 버튼이 표시되어 최신 알림 코드 적용을 확인했습니다.
- 번역 완료를 처음 관찰한 시점으로부터 **50,375ms 후**에도 **원문 복구** 버튼이 보였습니다.
- 그 버튼을 클릭해 한국어 입력 전체가 정확히 돌아왔고 **입력 원문을 복구했습니다.** 안내를 확인했습니다.
- 번역 완료 첫 관찰은 트리거 후 13,262ms였습니다. 연속 측정한 지연 시간이 아니므로 성능 벤치마크로 사용하지 않습니다.

로컬 증거: `artifacts/chrome-space3-persistent-1.2.1.png`, `artifacts/chrome-space3-restored-1.2.1.png`. 스크린샷과 사용자 프로필은 배포 ZIP 및 Git에서 제외합니다.

실제 Perplexity의 기존 테스트 대화에서도 최신 확장 코드를 적용해 검사했습니다. `퍼플렉시티에서 번역한 문장을 원문으로 복구합니다.`를 입력하고 스페이스 키를 세 번 눌러 `Restores sentences translated in Perplexity to their original text.`로 변경되는 것을 확인했습니다. **원문 복구**로 한국어 전체가 돌아왔고 **닫기** 버튼으로 안내를 닫았습니다. 질문은 전송하지 않았으며 테스트 후 입력창을 원래의 빈 상태로 돌렸습니다. 증거는 로컬 `artifacts/chrome-perplexity-translated-1.2.1.png`, `artifacts/chrome-perplexity-restored-1.2.1.png`입니다.

사용자 Chrome의 NVIDIA 페이지에서 이번 버전의 페이지 번역 시작은 아직 미확인입니다. 툴바 시작 버튼을 직접 누르는 단계는 도구 제약으로 사용자에게 요청했습니다. 아래 NVIDIA 통과 결과는 별도 Chrome for Testing 결과입니다.

## 별도 테스트 브라우저

사용자의 Chrome 프로필과 구분되는 Chrome for Testing에서 실행했습니다.

| 검사 | 결과 |
| --- | --- |
| JavaScript 구문·manifest 파일 검사 | 통과, 22개 JS 파일 |
| 텍스트·로컬 연결·인증·묶음 처리 단위 검사 | 17/17 통과 |
| 로컬 모의 응답을 사용하는 확장 회귀 검사 | 22/22 통과 |
| 실제 ChatGPT 로그인 E2E | 4/4 통과, API 키·모의 번역 미사용 |

회귀 검사에는 12.5초 이후 새 페이지 번역이 완료되어도 입력 복구가 유지되는 경우, 닫기 후 페이지 상태가 복원되는 경우, 사용자가 새로 쓴 내용을 복구 버튼이 덮어쓰지 않는 경우를 포함합니다. 모의 연결 서버는 18459 포트를 사용하여 사용 중인 18458 포트의 실제 로그인 연결을 방해하지 않습니다.

실제 ChatGPT E2E에서는 일반 입력창 및 Lexical 편집기의 스페이스 3회 번역과 복구를 확인했습니다. [NVIDIA ROS 2 문서](https://docs.isaacsim.omniverse.nvidia.com/latest/ros2_tutorials/index.html)에서는 22개 번역, 영어 원문·링크 보존, 페이지 원문 복원을 확인했습니다. 첫 12개는 12.855초, 스크롤과 원문 복구까지 23.835초였습니다. 페이지 번역과 동시에 요청한 입력 번역은 6.593초에 완료되어 복구까지 성공했습니다. 이 값은 해당 실행 1회의 측정이며 일반적인 속도를 보장하지 않습니다.

검사 원본은 로컬 `artifacts/regression-1.2.1.json`, `artifacts/login-1.2.1.json`에 보관합니다. Comet의 이전 실제 검증 범위는 [COMET.md](COMET.md)에 별도로 기록했습니다.
