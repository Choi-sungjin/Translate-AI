# 입력 복구 보완판 · 2026-10-24

번역이 끝난 뒤 입력창에서 초점을 옮기면, 텍스트를 수정하지 않았어도 원문 복구가 취소되는 문제를 수정했습니다. 복구 버튼에 키보드로 초점을 이동했을 때도 발생했습니다.

입력 내용 변경 이력과 초점 이동 이력을 구분합니다. 복구는 실제 편집 이력을 확인하며, 사용자가 내용을 바꿨다가 같은 번역문으로 되돌렸어도 예전 원문으로 덮어쓰지 않습니다. 번역 응답을 기다리는 동안의 초점 이동·새 입력 보호는 유지했습니다.

## 현재 설치 폴더에 적용

이 PC의 Git 작업 폴더에는 수정이 반영돼 있습니다. Chrome·Comet 각각 `chrome://extensions`에서 **Translate AI 새로고침**, 사용할 웹페이지에서 **F5**를 누릅니다. 이 보완판은 연결 프로그램을 바꾸지 않으므로 재시작하거나 연결 코드를 다시 저장할 필요가 없습니다.

다른 설치본은 [v1.3.0 릴리스](https://github.com/Choi-sungjin/Translate-AI/releases/tag/v1.3.0) 또는 [v1.4.0 릴리스](https://github.com/Choi-sungjin/Translate-AI/releases/tag/v1.4.0)의 `Translate-AI-restore-update-20261024.zip` 안 `extension/content.js`를 기존 설치 폴더의 같은 위치에 덮어쓰고 위 새로고침을 진행합니다. 이 ZIP은 공통 입력 처리 파일만 교체하므로 기존 버전·운영체제 실행 파일·설정이 유지됩니다. 전체 `extension` 폴더를 새로 로드하는 설치용 ZIP이 아닙니다.

GitHub main의 v1.4.0 Linux 지원 변경에도 같은 복구 수정을 합쳤습니다. 아래 설치 브라우저 실기 검사는 **Windows v1.3.0 + 복구 보완판** 기준이며, Linux 설치 브라우저를 이번 작업에서 재검증한 것은 아닙니다. Windows용 설명서의 v1.3.0 설치 순서를 v1.4.0 설치본의 다운그레이드 절차로 사용하지 마세요.
