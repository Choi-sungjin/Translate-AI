# Windows 연결 프로그램 재시작 보완

2026-10-18: 설치된 Chrome·Comet 확장은 모두 v1.3.0이었고, 두 브라우저의 팝업에서 GPT-6 Luna 선택과 저장 완료를 확인했습니다. 그러나 로컬 연결 프로그램은 v1.2.0 프로세스가 그대로 남아 있었습니다. Chrome의 실제 NVIDIA 검색창에서 스페이스 3회는 인식됐지만 연결 프로그램 업데이트 오류가 표시됐으며 입력 원문은 보존됐습니다.

기존 `Start-Translate-AI.cmd`는 실행 중인 연결 프로그램의 이름만 확인했습니다. 구버전도 준비 완료로 표시할 수 있어 원인 파악을 어렵게 했습니다. Stop 실행이 반영되지 않은 구체적인 이유는 아직 확인되지 않았습니다.

## 적용

1. Git 작업 폴더는 최신 `main`으로 업데이트합니다. 최초 v1.3.0 ZIP 설치는 릴리스의 `Translate-AI-1.3.0-launcher-update.zip`을 기존 설치 폴더에 덮어 풉니다. 기존 파일을 삭제하거나 연결 코드를 다시 저장할 필요는 없습니다.
2. Windows 파일 탐색기에서 **`Restart-Translate-AI.cmd`를 더블클릭해 실행**합니다. 편집기에서 파일 내용만 여는 것과 구분합니다.
3. 검은 창에 **`READY: Translate AI bridge v1.3.0, model selection enabled.`**가 나오면 연결 프로그램 재시작이 확인된 것입니다. 오류이면 창의 메시지를 확인하세요.
4. 이미 v1.3.0으로 새로고침한 확장은 다시 새로고침하지 않아도 됩니다. 대상 웹페이지에 최신 확장 코드가 로드돼 있어야 합니다.

## 변경과 검증

- 시작 시 확장 manifest와 실행 중인 연결 프로그램 버전이 다르면 명확한 오류를 표시합니다.
- 재시작은 기록된 PID가 이 프로젝트의 `node.exe`와 `bridge/server.mjs`에 일치할 때만 중지하며 종료를 기다립니다. 다른 앱의 포트, 다른 프로젝트의 PID, 처리 중인 번역은 재시작을 중단합니다.
- 재시작 결과 창을 유지하고 `%LOCALAPPDATA%\Translate-AI\restart-status.json`에 단계·시간·오류를 기록합니다. 인증 정보나 번역 원문은 기록하지 않습니다.
- 모의 검사 8개 통과: 구버전 거절, 다른 앱 포트 거절, 현 버전 재사용, 번역 중 재시작 거절, 다른 PID 거절, 재시작 후 정상 버전, PID 파일 없음, 잘못된 재시작 버전.

이 실행 파일 검사는 실제 사용자 프로세스를 재시작한 증거가 아닙니다. 설치된 두 브라우저의 Luna 번역·복구 최종 검증은 로컬 연결 프로그램의 성공적인 재시작 후 진행합니다. 기존 확장 v1.3.0 파일과 원래 릴리스 ZIP은 변경하지 않습니다.
