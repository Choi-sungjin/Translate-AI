02 / SETUP

처음 설치하고 ChatGPT에 연결하기

  1. 전체 패키지와 Node.js를 준비합니다.
    아래는 Windows v1.3.0의 검증된 설치 순서입니다. v1.3.0 릴리스의 Translate-AI-1.3.0-desktop.zip을 풀고 같은 폴더에 Translate-AI-1.3.0-launcher-update-r2.zip과 Translate-AI-restore-update-20261024.zip을 덮어 적용합니다. Node.js 22 이상이 필요합니다. v1.4.0을 사용 중이면 기존 설치를 유지하고 공통 복구 보완 ZIP만 적용하세요.
  2. Chrome와 Comet에 확장을 각각 로드합니다.
    주소창에 chrome://extensions → 개발자 모드 → 압축해제된 확장 프로그램을 로드합니다 → 패키지 안의 extension 폴더 선택. 두 브라우저는 설정을 공유하지 않으므로 각각 진행합니다.
  3. 로컬 연결 프로그램을 실행합니다.
    Start-Translate-AI.cmd를 더블클릭합니다. 첫 실행은 의존성 설치 때문에 시간이 더 걸릴 수 있습니다. 아래 주소가 연결 화면입니다.
http://127.0.0.1:18458/
  1. ChatGPT 로그인 상태를 확인합니다.
    기존 공식 Codex CLI 로그인을 재사용합니다. 로그인이 필요하다고 표시되면 프로젝트 폴더의 터미널에서 npx codex login을 실행하고 공식 로그인 화면에서 직접 완료합니다.
  2. 현재 연결 코드를 각 브라우저에 저장합니다.
    연결 화면 새로고침 → 연결 코드 복사 → 확장 설정 → 서비스 ChatGPT 계정 로그인 · Codex 연결 선택 → 로컬 연결 코드 붙여넣기 → 설정 저장.
  3. 상태와 실제 번역을 차례로 확인합니다.
    저장한 연결 상태 확인은 로그인 상태를 검사합니다. 저장한 설정으로 연결 확인은 예문을 실제로 번역합니다. 이후 사용할 웹페이지를 새로고침하세요.
연결 코드는 채팅에 보내지 마세요.

이 코드는 이 PC의 확장과 연결 프로그램을 짝짓는 값입니다. ChatGPT OAuth 토큰이나 API 키를 복사하는 과정은 없습니다.

확장만 들어 있는 ZIP에는 연결 프로그램이 없습니다. ChatGPT 계정 방식은 전체 패키지를 사용하세요. 종료할 때는 Stop-Translate-AI.cmd, 업데이트 후에는 Restart-Translate-AI.cmd를 실행합니다.

03 / READ & WRITE

번역하기와 원문 복구

웹페이지: 원문 아래에 번역을 더합니다

번역할 탭에서 확장 아이콘 → 이 페이지 번역하기. 원문과 링크는 유지되고 화면 가까이 있는 문단부터 번역이 표시됩니다. 원문만 보려면 같은 팝업의 원문만 보기를 누르세요.

표시 방식 예시

The robot publishes sensor data at 30 Hz.

로봇은 센서 데이터를 30Hz로 발행합니다.

페이지 단축키는 Alt+A입니다. Comet에서는 어시스턴트와 충돌할 수 있으므로 확장 아이콘을 이용하세요.

입력창: 문장을 쓴 뒤 Space 세 번

  1. 사이트 안의 검색창·텍스트 입력란을 클릭하고 문장을 씁니다.
  2. 한국어 조합을 마친 뒤 Space를 짧게 세 번 누릅니다. 길게 누르기는 해당하지 않습니다. 연속 누르는 간격의 기본값은 300ms입니다.
  3. 완료 알림과 번역된 문장을 확인합니다. 결과가 원하는 내용이면 직접 검색·전송합니다.
  4. 되돌리려면 완료 알림의 원문 복구를 누릅니다. 검색창은 열린 상태를 유지합니다.
복구 버튼은 시간 제한 없이 유지됩니다.

복구하거나 닫기 버튼을 누르거나 새 번역을 시작하면 알림이 바뀝니다. 일반 안내는 30초 뒤 닫힙니다. 번역 뒤 문장을 직접 수정했다면 예전 원문으로 덮어쓰지 않습니다.

연타가 어렵다면

설정에서 연타 허용 간격 → 여유 있게 · 500ms를 선택해 저장하세요. 입력창에 커서를 두고 Alt + I로 실행해도 됩니다.

번역을 기다리는 동안

입력 내용을 바꾸면 오래된 번역 결과로 덮어쓰지 않습니다. 새 문장을 번역하려면 다시 단축키를 실행하세요.

페이지 원문 복원과 입력 원문 복구는 서로 다른 기능입니다. 페이지는 확장 팝업, 입력은 완료 알림에서 되돌립니다.

04 / PREFERENCES

언어와 번역 모델 고르기

기본값은 웹페이지 → 한국어, 입력창 → 영어입니다. 확장 설정의 두 언어 항목을 따로 선택하고 설정 저장을 누릅니다. 스페이스바 기능도 이곳에서 켜거나 끌 수 있습니다.

ChatGPT 번역 모델 변경

확장 팝업의 ChatGPT 번역 모델은 선택 즉시 저장됩니다. 전체 설정에서 바꾸면 설정 저장을 눌러야 합니다. 다음 번역 요청부터 적용되며, 이미 번역된 페이지는 원문으로 돌린 뒤 다시 번역하세요.

모델선택 참고
GPT-6.1 Sol새 설치·기존 설정의 기본 모델. 작은 비교 시험에서는 두 Luna보다 느렸습니다.
GPT-6 Luna일상적인 입력 번역부터 시험해 볼 선택. 아래 비교에서 입력 번역이 가장 빨랐습니다.
GPT-5.6 Luna아래 비교에서 문단 묶음이 가장 빨랐습니다. 부정 표현·전문 용어는 원문과 대조하세요.

측정으로 보는 속도

2026-10-18 실제 계정 비교 · 모델/방식당 3회 · 중앙값 · 워밍업 제외. 네트워크·계정 상태·텍스트에 따라 달라지는 소규모 표본입니다.

번역 작업6.1 Sol6 Luna5.6 Luna
입력 문장7.53초5.68초6.00초
문단 3개 묶음8.70초6.75초6.01초

2026-10-24 연결 재검사에서 GPT-6 Luna는 입력 1건 7.14초, 문단 2개 묶음 5.19초였습니다. 이는 로컬 서버 요청의 왕복 시간이며 전체 페이지 완료 시간은 아닙니다.

가장 빠른 모델이 항상 같은 것은 아닙니다.

모든 모델은 추론 강도 low를 사용합니다. 기술 문서의 수치·단위·부정문은 원문과 비교하세요. 실제 시험에서도 ROS의 publish가 ‘게시’로 번역되는 용어 문제가 있었습니다.

계정에서 모델을 사용할 수 없으면 오류를 표시하며 다른 모델로 자동 전환하지 않습니다. 자세한 예문과 비교 방법: GitHub 저장소의 docs/MODELS-1.3.0.md.

내 텍스트는 어디로 가나요?

브라우저 확장→이 PC의 연결 프로그램→공식 Codex CLI · OpenAI

ChatGPT 계정 방식은 별도 API 키 없이 기존 CLI 인증을 사용하며 계정의 Codex 이용 한도를 소비합니다. 번역 대상 텍스트는 OpenAI로 전송됩니다. 로컬 연결 코드는 각 브라우저의 확장 저장소에 저장되고 동기화되지 않습니다. 로그인 토큰을 확장에 복사하지 않습니다.

현재 지원하는 범위

일반 HTTP/HTTPS 웹페이지, 텍스트·검색 입력란, textarea, 단순 contenteditable, 일반 텍스트 문단으로 구성된 Lexical 편집기를 지원합니다. 입력은 최대 12,000자이며 페이지당 최대 1,000개 문단을 추적합니다.

브라우저 주소창·내부 페이지·웹 스토어, PDF·자막, 닫힌 Shadow DOM, 복잡한 서식 편집기는 지원 범위에 포함하지 않습니다. 모든 사이트와 실제 Windows IME 키 조합을 검증한 것은 아닙니다. Gemini 계정 로그인도 이 버전에는 없습니다. 이 설명서의 실기 검사는 Windows v1.3.0 보완판 기준입니다. Linux 설치는 저장소 README를 참고하세요.
