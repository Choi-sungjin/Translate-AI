02   번역 서비스

이 PC의 Codex CLI에 로그인한 ChatGPT 계정으로 번역합니다. API 키는 필요하지 않으며, 계정의 Codex 사용량에 포함됩니다.

연결 프로그램 실행 방법 — Windows: Start-Translate-AI.cmd, Linux: sh Start-Translate-AI.sh (로그인 자동 시작: sh Install-Translate-AI.sh). 연결 화면에서 코드를 복사해 아래에 붙여넣고 저장하세요.

긴 문서는 시간이 걸리고 계정 사용량을 소비할 수 있습니다. 로그인이나 한도 오류 시 다른 서비스로 자동 전송하지 않습니다.

MyMemory의 공개 무료 API를 이용합니다. 익명 사용에는 일일 한도가 있어 긴 문서에는 개인 AI API나 ChatGPT 연결을 권장합니다. 번역할 텍스트가 MyMemory에 전송됩니다.

입력한 키는 이 브라우저의 확장 저장소에 저장되며 동기화되지 않습니다. 번역 텍스트는 지정한 서버에 전송됩니다. 키와 요청 본문을 로그로 남기지 않습니다.

페이지 번역 버튼이나 입력 번역 단축키를 실행했을 때만 번역을 요청합니다. 기록 수집과 분석용 추적은 없습니다.

번역 결과 캐시는 메모리에만 보관됩니다.
